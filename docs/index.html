    スプレッドシート接続（GAS）

    コピーしたリンクを別のスマホ・PCで開くと、URLと合言葉が自動で登録されます。人に送らないでください。

    初回セットアップ手順

    1. script.google.com で新しいプロジェクトを作成
    2. gas/Code.gs の中身を丸ごと貼り付けて保存
    3. 上部の関数で setup を選んで「実行」→ 権限を許可（記録用スプレッドシートが自動で作られます）
    4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、実行ユーザー「自分」、アクセス「全員」→ デプロイ
    5. 表示された URL をこの画面の「ウェブアプリURL」に貼り付けて保存
